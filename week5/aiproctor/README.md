# AI Proctor: Code Integrity & AI Detection System

An intelligent code proctoring system that evaluates code submissions to determine:
1. **Plagiarism between students/developers**: Built using a **MOSS (Measure of Software Similarity)** winnowing fingerprinting algorithm.
2. **AI-Generated Code Detection**: Built using a hybrid approach combining code-stylometric structural feature embeddings and **Groq LLM (`openai/gpt-oss-120b`)** forensic analysis.

---

## 🚀 Features

- **MOSS-Style Plagiarism Detection**:
  - Code normalization (removes comments, normalizes whitespace and structure).
  - Rolling k-gram hashing and winnowing windowing for fingerprint selection.
  - Jaccard similarity scoring and exact line-level matching.
- **AI-Generated Code Detection**:
  - Heuristic & structural feature extraction: docstring density, type annotation ratio, naming consistency, indentation complexity uniformity, line-length distribution.
  - Groq LLM integration (`openai/gpt-oss-120b`) for deep code-forensic reasoning.
  - Weighted combination confidence score and verdict.
- **Dual Interface**:
  - **Streamlit Web UI**: Interactive dashboard with real-time gauges, side-by-side matching regions, and pairwise similarity heatmaps.
  - **CLI**: Fast terminal-based proctoring tool.

## 🛠️ Installation & Setup

1. **Virtual Environment & Dependencies**:
   ```bash
   uv sync
   # or: pip install -e .
   ```

2. **Configure API Keys**:
   Ensure `.env` contains your Groq API key:
   ```env
   GROQ_API_KEY=gsk_your_groq_api_key_here
   ```

## 💻 Usage

### 1. Web Dashboard (Streamlit)
To launch the interactive proctoring interface:
```bash
.venv\Scripts\streamlit run src/aiproctor/app.py
```
- **Plagiarism Tab**: Compare two files or paste snippets side-by-side.
- **AI Detection Tab**: Check if code is generated by AI, inspect features and LLM explanations.
- **Full Analysis Tab**: Upload an entire batch of student submissions for a pairwise similarity matrix and AI breakdown.

### 2. Command Line Interface (CLI)

- **Plagiarism check between two files**:
  ```bash
  .venv\Scripts\python -m aiproctor.cli plagiarism samples/student_a_sorting.py samples/student_b_sorting.py
  ```

- **AI-generated code detection on a single file**:
  ```bash
  .venv\Scripts\python -m aiproctor.cli ai-detect samples/ai_generated_calculator.py
  ```

- **Full batch analysis**:
  ```bash
  .venv\Scripts\python -m aiproctor.cli full samples/student_a_sorting.py samples/student_b_sorting.py samples/student_c_sorting.py
  ```
